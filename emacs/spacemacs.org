This is the literate Spacemacs configuration for my NixOS dotfiles.  Each
section documents *why* a piece of configuration exists so that the intent
stays clear over time.

The Org file is tangled at Nix build time (=emacs --batch= with
=org-babel-tangle-file=) to produce the =.spacemacs= that Spacemacs loads.
Nix path substitution placeholders (=__MU_BIN__=, etc.) are replaced after
tangling, just as before.

* Layers

The =dotspacemacs/layers= function declares which Spacemacs layers to load,
additional packages that aren't part of any layer, and packages to exclude.

The layers are organized as:

- *Core*: =better-defaults=, =git=, =org= — standard productivity
- *Completion*: =auto-completion= (with snippets), =spell-checking=,
  =syntax-checking=, =ivy=, =lsp=, =treemacs=
- *Languages*: C/C++ (clangd), Claude Code, CMake, Docker, Markdown, Nix,
  PDF, Python (pyright), YAML, ERC (IRC), Rust, Shell
- *Communication*: =mu4e= (email), =erc= (IRC), =slack=, =spotify=
- *Tools*: =tabs= (centaur-tabs), =shell= (vterm), =shell-scripts=

Additional packages (=gruvbox-theme=, =vterm=, =clipetty=, etc.) are
installed outside layers.  =forge= is excluded to avoid pulling in heavy
Git forge dependencies.

* User Init

Runs early, before layers are loaded.  Used for performance tuning and
disabling UI chrome that would otherwise flash on startup.

** Performance tuning

Raise the GC threshold to maximum and disable =file-name-handler-alist=
during startup so that package initialization doesn't trigger excessive
garbage collection or regex matching.  After startup, =gcmh= takes over
GC management (collecting only during idle time).
=fast-but-imprecise-scrolling=, =redisplay-skip-fontification-on-input=,
and =jit-lock-defer-time= improve interactive responsiveness.
=inhibit-compacting-font-caches= prevents GC stalls from font cache
compaction in GUI frames.  Bidi scanning is disabled (LTR-only) and
=scroll-conservatively= avoids jarring recentering jumps.
=lsp-use-plists= enables plist-based LSP deserialization which is
significantly faster than the default hash-table mode.

** UI chrome removal

Disable menu bar, toolbar, scrollbar, blinking cursor, tooltips, fringes,
and tab-bar so the editor starts with a clean, distraction-free look.

** Native compilation warnings

Silence native-compilation async warnings that would otherwise pop up
buffers during normal editing after a fresh rebuild.

** Frame defaults

Remove the internal border so that tiling window managers (Sway) get a
seamless appearance.

#+begin_src emacs-lisp
(defun dotspacemacs/user-init ()
  ;; Bypass file-name-handler-alist during startup (restored after init).
  (defvar my/file-name-handler-alist-backup file-name-handler-alist)
  (setq file-name-handler-alist nil)
  (add-hook 'emacs-startup-hook
            (lambda ()
              (setq file-name-handler-alist my/file-name-handler-alist-backup)))

  ;; Use plist deserialization for lsp-mode (faster than hash-tables).
  (setenv "LSP_USE_PLISTS" "true")
  (setq lsp-use-plists t)

  ;; Startup and LSP defaults tuned for interactive work rather than cold-start demos.
  (setq gc-cons-threshold most-positive-fixnum
        gc-cons-percentage 0.6
        read-process-output-max (* 4 1024 1024)
        idle-update-delay 1.0
        fast-but-imprecise-scrolling t
        redisplay-skip-fontification-on-input t
        inhibit-compacting-font-caches t
        site-run-file nil
        jit-lock-defer-time 0.05)

  ;; Avoid expensive bidi reordering scans (only LTR text in this setup).
  (setq-default bidi-display-reordering 'left-to-right
                bidi-paragraph-direction 'left-to-right)
  (setq bidi-inhibit-bpa t)

  ;; Smooth scrolling without recentering jumps.
  (setq scroll-conservatively 101
        scroll-margin 2
        auto-window-vscroll nil)
  (setq-default cursor-type '(hbar . 3)
                line-spacing 2)
  (menu-bar-mode -1)
  (tool-bar-mode -1)
  (scroll-bar-mode -1)
  (blink-cursor-mode -1)
  (when (fboundp 'tooltip-mode)
    (tooltip-mode -1))
  (when (fboundp 'set-fringe-mode)
    (set-fringe-mode 4))
  (when (fboundp 'tab-bar-mode)
    (tab-bar-mode -1))
  (when (boundp 'native-comp-async-report-warnings-errors)
    (setq native-comp-async-report-warnings-errors 'silent))
  (when (boundp 'comp-async-report-warnings-errors)
    (setq comp-async-report-warnings-errors 'silent))
  (when (boundp 'warning-suppress-types)
    (add-to-list 'warning-suppress-types '(native-compiler)))
  (add-to-list 'default-frame-alist '(internal-border-width . 0)))
#+end_src

** General settings

Whitespace display (trailing whitespace and tab marks) and frame-title
suppression for a cleaner tiling WM experience.

#+begin_src emacs-lisp
(defun dotspacemacs/user-config ()
  (setq-default
   whitespace-style '(face trailing tabs tab-mark)
   whitespace-line-column 100)

  (setq frame-title-format nil
        indicate-buffer-boundaries nil
        indicate-empty-lines nil)

  ;; Which-Key: use a bottom side-window.  Keep keystroke echo in the echo
  ;; area (not in the which-key popup).  Remove the mode-line on the popup
  ;; window and grow by 1 line to avoid overlap with the echo area.
  (with-eval-after-load 'which-key
    (setq which-key-popup-type 'side-window
          which-key-side-window-location 'bottom
          which-key-show-prefix 'echo)
    ;; Hide the mode-line and grow by 1 line for clearance above echo area.
    (defun my/which-key-adjust-window (&rest _)
      (when-let ((win (get-buffer-window which-key--buffer)))
        (with-selected-window win
          (setq-local mode-line-format nil)
          (ignore-errors (enlarge-window 1))))
      (run-at-time 0 nil
                   (lambda ()
                     (when-let ((win (get-buffer-window which-key--buffer)))
                       (with-selected-window win
                         (setq-local mode-line-format nil)
                         (ignore-errors (enlarge-window 1)))))))
    (advice-add 'which-key--show-popup :after #'my/which-key-adjust-window))

  ;; Pixel-precise smooth scrolling (Emacs 29+).
  (when (fboundp 'pixel-scroll-precision-mode)
    (pixel-scroll-precision-mode 1))

  ;; Protect against accidentally opening huge/minified files.
  (when (fboundp 'global-so-long-mode)
    (global-so-long-mode 1))

  ;; Pretty Org mode display
  (setq org-startup-indented t
        org-hide-emphasis-markers t
        org-pretty-entities t
        org-ellipsis " ▾")
  (add-hook 'org-mode-hook #'visual-line-mode)
  (setq org-superstar-headline-bullets-list
        '(?◉ ?○ ?◆ ?◇ ?▶ ?▷))

  ;; Center prose in Org buffers on wide monitors
  (setq visual-fill-column-width 100
        visual-fill-column-center-text t)
  (add-hook 'org-mode-hook #'visual-fill-column-mode)
#+end_src

** Copilot CLI

The GitHub Copilot CLI integration.  Opens a dedicated vterm panel on the
right side of the frame.  The buffer name and regexp are used by
=display-buffer-alist= to control placement.  Invoked with =SPC a a C=.

#+begin_src emacs-lisp
  (defconst my/copilot-cli-buffer-name "*Copilot CLI*"
    "Buffer name for the dedicated Copilot CLI panel.")

  (defconst my/copilot-cli-buffer-regexp "^\\*Copilot CLI\\*$"
    "Match the dedicated Copilot CLI buffer.")

  (defun my/copilot-cli ()
    (interactive)
    (let ((copilot-program (executable-find "copilot")))
      (unless copilot-program
        (user-error
         "The `copilot` CLI is not installed in this profile; run Home Manager switch and restart Emacs."))
      (unless (fboundp 'vterm)
        (user-error "vterm is unavailable; run Home Manager switch and restart Emacs"))
      (let* ((default-directory
               (or (and buffer-file-name (file-name-directory buffer-file-name))
                   default-directory))
             (buffer (get-buffer my/copilot-cli-buffer-name))
             (live-process (and buffer (get-buffer-process buffer))))
        (if live-process
            (display-buffer buffer)
          (vterm my/copilot-cli-buffer-name)
          (setq buffer (current-buffer))
          (vterm-send-string copilot-program)
          (vterm-send-return))
        (when-let ((window (get-buffer-window buffer t)))
          (select-window window)))))
#+end_src

** GC and startup hooks

After startup, =gcmh= manages garbage collection (only collecting during
idle time with a 64 MB threshold).  Transient buffers (*scratch*,
*Messages*, *info*) are removed after a short delay to keep the home view
clean.

#+begin_src emacs-lisp
  ;; Use gcmh for idle-time-only garbage collection after startup.
  (use-package gcmh
    :demand t
    :config
    (setq gcmh-idle-delay 'auto
          gcmh-auto-idle-delay-factor 10
          gcmh-high-cons-threshold (* 64 1024 1024))
    (gcmh-mode 1))

  (add-hook 'emacs-startup-hook
            (lambda ()
              (run-with-idle-timer 1 nil #'my/remove-startup-buffers)))

  (setq initial-buffer-choice
        (lambda ()
          (when (fboundp 'spacemacs-buffer/goto-buffer)
            (spacemacs-buffer/goto-buffer nil t))
          (get-buffer "*spacemacs*")))
#+end_src

** mu4e-alert query and mode-line formatter

The unread-mail query is limited to folders the user actively monitors
(Inbox, Promotions, Social Networks).  The mode-line formatter uses the
same Nerd Font mail glyphs as Waybar.

#+begin_src emacs-lisp
  (defconst my/mu4e-alert-query
    "flag:unread AND NOT flag:trashed AND (maildir:/ludovic/Index OR maildir:/ludovic/Promotions OR maildir:/ludovic/SocialNetworks)"
    "Unread mail query limited to the folders the user cares about.")

  (defconst my/mu-binary "__MU_BIN__"
    "Path to the mu binary rendered by Home Manager.")

  (defvar my/mail-unread-count 0
    "Cached unread mail count for the mode-line.")

  (defvar my/mail-unread-count-timer nil
    "Timer used to refresh `my/mail-unread-count'.")

  (defvar mu4e-alert-mode-line nil
    "Mode-line string consumed by Spaceline's mu4e-alert segment.")

  (defun my/mail-unread-count-from-mu ()
    "Return unread mail count using the same mu query as Waybar."
    (when (and (file-executable-p my/mu-binary)
               (file-directory-p (expand-file-name "~/.cache/mu")))
      (with-temp-buffer
        (let ((status (call-process my/mu-binary nil t nil
                                    "find" "--nocolor" "--format=plain"
                                    my/mu4e-alert-query)))
          (when (eq status 0)
            (let ((count 0))
              (goto-char (point-min))
              (while (not (eobp))
                (unless (looking-at-p "^[[:space:]]*$")
                  (setq count (1+ count)))
                (forward-line 1))
              count))))))

  (defun my/refresh-mail-unread-count (&rest _)
    "Refresh the cached unread mail count and repaint mode-lines."
    (let ((count (my/mail-unread-count-from-mu)))
      (when (integerp count)
        (setq my/mail-unread-count count)
        (when (boundp 'mu4e-alert-mode-line)
          (setq mu4e-alert-mode-line
                (my/mu4e-alert-mode-line-formatter count)))
        (force-mode-line-update t))))

  (defun my/start-mail-unread-count-refresh ()
    "Start the Waybar-style unread mail refresh timer."
    (my/refresh-mail-unread-count)
    (unless (timerp my/mail-unread-count-timer)
      (setq my/mail-unread-count-timer
            (run-with-timer 30 30 #'my/refresh-mail-unread-count))))

  (defun my/mu4e-alert-mode-line-formatter (_mail-count)
    "Return empty string — mail info is shown on the right side of the bar."
    "")

** Shell / vterm

Detect the Fish shell from several candidate paths (Nix profile, system
path) and configure vterm, multi-term, and the =$SHELL= environment
variable.  Also redirect =M-x shell= to vterm so we never get a
=TERM=dumb= buffer.

#+begin_src emacs-lisp
  (let* ((fish-candidates (list
                           (executable-find "fish")
                           (expand-file-name "~/.nix-profile/bin/fish")
                           (expand-file-name "~/.local/state/nix/profile/bin/fish")
                           "/run/current-system/sw/bin/fish"))
         (fish (seq-find #'file-executable-p fish-candidates)))
    (when fish
      (setq shell-file-name fish
            explicit-shell-file-name fish
            vterm-shell fish
            vterm-max-scrollback 10000
            multi-term-program fish)
      (setenv "SHELL" fish)))

  ;; Redirect M-x shell to vterm so we never get TERM=dumb.
  (defalias 'shell 'vterm)
#+end_src

** Copilot Chat (native Emacs buffer)

=copilot-chat= provides a fully scrollable Copilot chat interface
inside a native Emacs org-mode buffer.  Unlike the vterm-based CLI
(which uses the terminal alternate screen), this buffer supports
normal Emacs scrolling, search, and yank.

- =SPC a a h= opens the chat buffer (mnemonic: "h" for help/chat).
- =C-c C-c= or =C-c RET= sends the prompt from the input area.
- =SPC a a e= explain selected region.
- =SPC a a r= review selected region.
- =SPC a a f= fix selected region.
- =SPC a a t= generate tests for selected region.

The vterm CLI (=SPC a a C=) remains available for agentic tasks.

#+begin_src emacs-lisp
  (with-eval-after-load 'copilot-chat

    (customize-set-variable 'copilot-chat-backend 'curl)

    ;; Ensure prompt-mode keybindings (C-c C-c / C-c RET to send) work in the
    ;; base buffer even when polymode fails to switch to the inner indirect buffer.
    (add-hook 'copilot-chat-org-poly-mode-hook #'copilot-chat-prompt-mode))

** Mode-line (spaceline)

Override the Spacemacs spaceline modeline faces with Gruvbox Dark Hard
palette colours.  We do NOT rebuild the spaceline theme — Spacemacs
already includes =mu4e-alert-segment=, =global=, and all standard
segments.  We only repaint the faces after each spaceline compilation.
The Spacemacs home buffer normally hides its mode-line with a buffer-local
empty value, so restore the stock Spaceline value there instead of creating
a separate home-only mode-line.  Keep the existing =mu4e-alert-segment=
high enough in Spaceline's responsive priority order that the mail count
survives normal narrow-window pruning.

#+begin_src emacs-lisp
  (defun my/spaceline-segment-spec-matches-p (spec segment)
    "Return non-nil when Spaceline SPEC contains SEGMENT."
    (or (eq spec segment)
        (and (consp spec)
             (or (eq (car spec) segment)
                 (and (consp (car spec))
                      (memq segment (car spec)))))))

  (defun my/spaceline-segment-index (segments segment)
    "Return the index of SEGMENT in Spaceline SEGMENTS."
    (let ((index 0)
          found)
      (while (and segments (not found))
        (when (my/spaceline-segment-spec-matches-p (car segments) segment)
          (setq found index))
        (setq segments (cdr segments)
              index (1+ index)))
      found))

  (defun my/prioritize-mu4e-alert-spaceline-segment (&rest _)
    "Keep Spaceline's existing mu4e-alert segment visible in normal widths."
    (when (and (boundp 'spaceline--mode-lines)
               (boundp 'spaceline--segments-code-main-left))
      (let* ((main (cdr (assq 'main spaceline--mode-lines)))
             (left-spec (car main))
             (index (my/spaceline-segment-index left-spec 'mu4e-alert-segment))
             (left-data (default-value 'spaceline--segments-code-main-left)))
        (when (and index (< index (length left-data)))
          (let ((runtime (nth index left-data)))
            (aset runtime 0 99)
            (aset runtime 2 t))
          (dolist (buffer (buffer-list))
            (with-current-buffer buffer
              (kill-local-variable 'spaceline--segments-code-main-left)
              (kill-local-variable 'spaceline--segments-code-main-right)
              (kill-local-variable 'spaceline--runtime-data-main)))))))

  (defun my/restore-spacemacs-home-spaceline (&rest _)
    "Use the regular Spaceline mode-line on the Spacemacs home buffer."
    (when (and (boundp 'spacemacs-buffer-name)
               (default-value 'mode-line-format))
      (let ((buffer (get-buffer spacemacs-buffer-name)))
        (when buffer
          (with-current-buffer buffer
            (setq-local mode-line-format (default-value 'mode-line-format))
            (force-mode-line-update))))))

  (with-eval-after-load 'core-spacemacs-buffer
    (unless (advice-member-p #'my/restore-spacemacs-home-spaceline

** mu4e stale-lock cleanup

When the mu server process dies unexpectedly it can leave the Xapian
database locked.  The advice below kills any orphaned =mu= processes
before (re)starting the server so mu4e recovers automatically.

#+begin_src emacs-lisp
  (defun my/mu4e-kill-stale-mu-processes ()
    "Kill any mu processes holding the Xapian database lock.
Called before starting the mu server so mu4e can acquire the lock."
    (let ((mu-pids
           (split-string
            (string-trim
             (shell-command-to-string
              (format "pgrep -u %s -x mu 2>/dev/null" (user-login-name))))
            "\n" t)))
      (when mu-pids
        (message "mu4e: found %d stale mu process(es), terminating: %s"
                 (length mu-pids) (string-join mu-pids ", "))
        (dolist (pid mu-pids)
          (let ((pid-num (string-to-number pid)))
            (when (> pid-num 0)
              (signal-process pid-num 15))))
        (sleep-for 1)
        (let ((remaining
               (split-string
                (string-trim
                 (shell-command-to-string
                  (format "pgrep -u %s -x mu 2>/dev/null" (user-login-name))))
                "\n" t)))
          (dolist (pid remaining)
            (let ((pid-num (string-to-number pid)))
              (when (> pid-num 0)
                (message "mu4e: force-killing stale mu process %d" pid-num)
                (signal-process pid-num 9))))
          (when remaining
            (sleep-for 0.5))))))

  (with-eval-after-load 'mu4e
    (when (fboundp 'mu4e--server-start)
      (advice-add 'mu4e--server-start :before
                  #'my/mu4e-kill-stale-mu-processes)))
#+end_src

** Treemacs

Keep Treemacs in sync with the current project and buffer via follow mode.
Also add a custom icon mapping for =CMakeLists.txt= (the default only
covers =.cmake= files).

#+begin_src emacs-lisp
  ;; Keep Treemacs in sync with the current project/buffer.
  (with-eval-after-load 'treemacs
    ;; Treemacs ships a CMake icon for `.cmake` files but not for the
    ;; canonical `CMakeLists.txt` filename, so add that explicit mapping.
    (when (fboundp 'treemacs-define-custom-icon)
      (treemacs-define-custom-icon (treemacs-icon-for-mode 'cmake-mode)
                                   "cmakelists.txt"))
    (treemacs-follow-mode t)
    (treemacs-filewatch-mode t)
    (treemacs-project-follow-mode t))
#+end_src

** Autosave

Automatically save visited file buffers every 30 seconds.  This uses the
built-in =auto-save-visited-mode= which writes directly to the visited
file (no =\#file\#= temporaries) and is safe for version-controlled
projects.

#+begin_src emacs-lisp
  (setq auto-save-visited-interval 30)
  (auto-save-visited-mode 1)
#+end_src
